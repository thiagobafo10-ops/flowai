# Fase 6 — Agente de IA, base de conhecimento e RAG — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agente de IA por organização que classifica e responde mensagens do Simulador e do Direct do Instagram com RAG sobre a base de conhecimento, com proteções contra invenção de fatos, transferência para humano, limite diário e área de teste.

**Architecture:** Lógica pura de IA (schemas, chunking, prompt, guardrails, pipeline) em `packages/core/src/ai`, testada com provider falso. Banco: fila `ai_jobs` alimentada por triggers em `messages`/`knowledge_documents`, funções SECURITY DEFINER de reserva/conclusão, `match_knowledge_chunks`, cota diária; `pg_cron` a cada 5 s chama `dispatch_ai_worker()` → Edge Function `ai-worker` (padrão do `instagram-worker`). Edge Function `ai-playground` (JWT do usuário) roda o mesmo pipeline sem gravar. Telas `/ia` e `/conhecimento` e ajustes no Inbox.

**Tech Stack:** Postgres 17 + pgvector 0.8.2 + pg_cron 1.6.4 + pgmq/pg_net (Supabase local), Deno 2 Edge Functions, TypeScript + Zod 4 (`packages/core`), Next.js 16 App Router + React Query + React Hook Form + shadcn/ui, Vitest, pgTAP, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-12-fase-6-ia-design.md` (base: `docs/superpowers/specs/2026-10-07-flowai-mvp-design.md` §7).

- Nenhum teste chama a OpenAI real nem a Graph API real.
- Modelos por env: `AI_CHAT_MODEL` (padrão `gpt-4.1-mini`), `AI_EMBEDDING_MODEL` (padrão `text-embedding-3-small`, 1536 dimensões); base URL `OPENAI_BASE_URL` (padrão `https://api.openai.com/v1`).
- Limites padrão: 300 respostas e 30 testes por organização por dia (dia no fuso `organizations.timezone`).
- Agrupamento: tarefa `reply` com `run_after = now() + interval '4 seconds'`; cron `'5 seconds'`; reserva expira em 3 min; tentativas: 3, esperas 10 s / 30 s / 90 s.
- Chunking ~800 tokens (estimativa `ceil(chars/4)`), sobreposição de 100 tokens; RAG k=5, `min_similarity = 0.3`.
- Histórico do prompt: últimas 20 mensagens não internas. Área de teste: até 10 mensagens, cada uma ≤ 1000 caracteres.
- Upload `.txt`/`.md` até 1 MB (1.048.576 bytes), UTF-8 estrito; o arquivo não é armazenado.
- Texto da transição ao cliente, exato: `Vou te encaminhar para um atendente, só um instante.`
- Copy de UI em pt-BR. `last_error`/logs nunca contêm texto de mensagens ou documentos.
- Códigos de transferência (`handoff_reason`) e rótulos exatos:
  - `needs_human` → `Cliente precisa de atendimento humano`
  - `no_knowledge` → `IA sem informação na base de conhecimento`
  - `unverified_fact` → `IA citou um valor que não está na base`
  - `injection` → `Possível tentativa de manipulação da IA`
  - `quota_exceeded` → `Limite diário da IA atingido`
  - `not_configured` → `IA não configurada na plataforma`
  - `ai_failure` → `Falha temporária da IA`
  - `window_closed` → `Fora da janela de 24h do Instagram`
  - `reply_too_long` → `Resposta da IA longa demais para o canal`

## Review Focus

1. **Mensagem chega enquanto a tarefa está `running`** → nasce uma nova tarefa `pending` (o índice único só cobre `pending`); a conclusão da tarefa em curso não pode cancelá-la. Teste no Task 6 (`017_ai_reply_queue`).
2. **Humano assume enquanto a IA está gerando** → `complete_ai_reply` revalida e descarta (nenhuma mensagem da IA é gravada). Teste no Task 6.
3. **OpenAI devolve JSON inválido ou fora do schema** → `AIProviderError('invalid_response')`, retry e, esgotadas as tentativas, transferência `ai_failure`. Teste no Task 7 (Deno) e Task 2 (core, schema).
4. **Formatos numéricos pt-BR** (`R$ 1.299,90` vs `1299,90 reais` vs `R$1299.90`) → mesmo valor é reconhecido; valor diferente é bloqueado. Teste no Task 2.
5. **Janela de 24h fechada no momento da conclusão** (retries atrasaram a resposta) → transferência `window_closed` sem criar intent. Teste no Task 6.
